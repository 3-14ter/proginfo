1. CSS alapok I

Itt egyenként végig lehet menni a szintaxison, a CSS beágyazásán, a szelektorokon, a mértékegységeken és a szövegformázáson. A dobozmodell külön, nagy ábrákkal és élő példákkal kapott saját oldalt.

CSS szintaxis

szelektor {
    tulajdonsag: ertek;
}

A szelektor kiválasztja az elemet, a kapcsos zárójelek között pedig a formázásokat adjuk meg.

Ez a sor internal CSS-t használ.

Alapvető szelektorok

  • p - elem szelektor
  • .kartya - class szelektor
  • #kiemelt-kozlemeny - id szelektor
  • * - univerzális szelektor
