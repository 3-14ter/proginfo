Reggel korán keltem, mert aznap fontos előadásom volt az egyetemen. Gyorsan összepakoltam a jegyzeteimet, majd elindultam a buszmegálló felé. Útközben találkoztam az egyik csoporttársammal, ezért együtt folytattuk az utat. Az első órán egy érdekes feladatot kaptunk, amelyet párokban kellett megoldanunk. A szünetben elmentünk a büfébe, ahol vettem egy kávét és egy szendvicset. Délután még könyvtárba is mentem, mert szerettem volna felkészülni a következő heti dolgozatra. Este fáradtan értem haza, de örültem annak, hogy sikerült minden fontos feladatot elvégeznem.
