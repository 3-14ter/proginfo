Pozicionálás

Először egyszerű dobozokon nézzük meg, honnan mérjük az eltolást, és melyik elemnek marad hely a sorban. Ezek után helyezzük a fénykardot a cica mancsába.

Normál helyzet: static

Az A, B és C doboz a HTML sorrendjében, egymás alatt jelenik meg. A B doboz position: static beállítású; ez az alapértelmezés. Kapcsold be a top: 20px és left: 35px értékeket. A B nem mozdul el: static mellett ezek az eltolások nem hatnak.

Eltolás a saját helyhez képest: relative

A B most position: relative beállítást kap. A top: 20px a saját eredeti helyéhez képest 20 pixellel lefelé, a left: 35px 35 pixellel jobbra viszi. Az eltolás nem a szülő sarkától indul. A C helye változatlan marad: a B eredeti helyét a többi elem továbbra is foglaltnak tekinti.

Hely megadása a szülőn belül: absolute

A keret position: relative beállítású, a B pedig position: absolute. A B top és left értékét ezért a keret belső bal felső sarkától mérjük. Kezdetben top: 20px és left: 120px; a kapcsolóval top: 100px és left: 40px lesz. Az A után a C következik a normál elrendezésben: az absolute B számára nem marad külön hely.

Hely az ablakhoz képest: fixed

A position: fixed elem helyét itt a böngészőablakhoz képest adjuk meg. A top: 100px 100 pixel távolságot jelent az ablak tetejétől; a right: 20px a jobb szélétől. Kapcsold be a jelzést, majd görgess. A többi tartalom továbbhalad, de a jelzés ugyanott marad.

A fixed jelzés megjelenítése

Bekapcsolás után görgesd az oldalt. A jelzés az ablak jobb felső részén marad. Kikapcsoláshoz vedd ki a pipát.

fixed top: 100px; right: 20px;

Az oldal jobb alsó sarkában lévő felfelé nyíl is fixed beállítású.

Mutasd a kódot + 
<span class="window-marker">
  fixed
</span>
.window-marker {
  position: fixed;
  top: 100px;
  right: 20px;
}

Görgetés közben tapadó elem: sticky

A sticky elem először a tartalommal együtt mozog. Kapcsold be, majd görgess a jobb oldali keretben. Amikor az elem eléri a top: 0 határt, a keret tetején marad, amíg a szülője területe engedi. Itt a görgethető keret tetejéhez tapad; a fixed példában a teljes böngészőablakhoz igazodtunk.

Itt kezdődik a görgethető tartalom.

Ez az elem tapad a tetejéhez.

Második bekezdés. Görgess tovább a kereten belül.

Harmadik bekezdés. A többi tartalom elhalad az elem mögött.

Utolsó bekezdés a szülő területén belül.

Görgetés: egérrel, érintéssel vagy a keretre lépve a nyílbillentyűkkel.

A position értékei

position: static
Az alapértelmezett beállítás. Az elem a HTML-ben megadott sorrend szerint helyezkedik el. Ha megadunk neki például top: 20px-t, attól még nem mozdul el.
position: relative
Az elemet az eredeti helyéhez képest toljuk el. A top: 20px például 20 pixellel lejjebb viszi. A többi elem úgy helyezkedik el, mintha nem mozdítottuk volna el.
position: absolute
Az elem helyét külön adjuk meg, a többi elem nem hagy neki helyet. A top és left a legközelebbi olyan őshöz igazodik, amelynek position értéke nem static. A példában ez a relative szülő. Nem mindig a közvetlen szülő a viszonyítási pont.
position: fixed
Az elem a böngészőablakhoz igazodik. Görgetés közben is ugyanott látszik. Ilyen az oldal jobb alsó sarkában lévő felfelé mutató nyíl.
position: sticky
Az elem először együtt mozog az oldallal. Ha eléri a megadott határt, ott marad a szülője területén belül. A felső menü például top: 0 mellett az ablak tetején marad.

FLOAT + CLEAR

Szöveg a droid körül

A float: left balra úsztatja a képet, a szöveg pedig körbefutja. Miau-D2 mindig segít a kiképzésben.

clear: both; Innen újra teljes sorban folytatjuk.

CSS megtekintése 
.float-example img {
  float: left;
  width: 64px;
  margin-right: 16px;
}

.clear-example {
  clear: both;
}

Z-INDEX

Ki van elöl?

A Jedi-lap z-index értéke
JEDI z-index: 1 z-index: -1 z-index: 3 FEDŐLAP z-index: 0 SITH z-index: 2

Az 1-es Jedi-lap a 0-s fedőlap előtt, a 2-es Sith-lap mögött van. A 3-as Jedi előre kerül. A -1-es Jedi a fedőlap mögé kerül: a takart része nem látszik. A negatív érték hátrébb helyez, nem törli az elemet.

A szülő position: relative és z-index: 0 beállítása ebben a példában közös rétegezési környezetet hoz létre. A -1-es lap így ezen a jeleneten belül marad.

CSS megtekintése 
.layer-demo {
  position: relative;
  z-index: 0;
}

.jedi-layer {
  position: absolute;
  z-index: -1;
}

.zero-layer {
  position: absolute;
  z-index: 0;
}

.sith-layer {
  position: absolute;
  z-index: 2;
}

Hogyan kerül a kard a mancsba?

A cicát és a kardot ugyanabba a div-be tesszük. Ez a jelenet. A jelenet position: relative beállítást kap, a kard pedig position: absolute-ot. Így a kard helyét a jelenet bal felső sarkától mérhetjük: a top a felső szélétől, a left a bal szélétől megadott távolság.

A fénykard helyzete
0, 0 ↘ top: 172px; left: 20px; top: 120px; left: 160px; top: 32px; left: 35px;

A kard külön HTML-elem. A helyét a CSS határozza meg.

</> Mutasd a kódot position + top + left + 
<div class="position-scene">
  <img src="../assets/jedi-cat.svg" alt="Jedi cica">
  <div class="practice-saber">
    …
  </div>
</div>
.position-scene {
  position: relative;
  width: 260px;
  height: 320px;
}

.practice-saber {
  position: absolute;
  top: 120px;
  left: 160px;
  z-index: 2;
}

A kard teteje 120 pixelre van a jelenet felső szélétől, bal széle pedig 160 pixelre a jelenet bal szélétől. A jelenet mérete ebben a példában 260 × 320 pixel.
