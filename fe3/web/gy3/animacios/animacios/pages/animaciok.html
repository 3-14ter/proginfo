Animációk

Először egy dobozt mozgatunk, és példánként egy új beállítást próbálunk ki. A végén ugyanezekből állítjuk össze a cicadroid lebegését.

A kódrészletek az animált állapot beállításait mutatják. Az Indítás kapcsolóval lejátszhatod a példát; kikapcsolva visszatér az alaphelyzet.

A dobozos példák alapja: HTML és CSS + 
<div class="animation-track">
  <div class="animation-box once-box">
    B
  </div>
</div>
.animation-track {
  padding: 20px;
  width: 230px;
  height: 90px;
}

.animation-box {
  position: relative;
  left: 0;
  width: 44px;
  height: 44px;
  background-color: #98bdf1;
}

A position: relative miatt a left a doboz saját alaphelyzetétől számít. Az animation-box a közös megjelenés, a once-box pedig az első példa animációs beállításait kapja. A későbbi példákban ez a második class változik.

A doboz egyszer elmozdul

A doboz kezdetben a bal oldalon áll. A @keyframes elore leírja, hogy a left értéke 0-ról 140px-re változzon. A from a kezdet, a to a vég.

Az animation-name kapcsolja a mozgást a dobozhoz. Az animation-duration: 2s két másodperces lejátszást ad. A linear miatt a sebesség végig egyenletes.

Kattints az Indításra. A doboz egyszer végighalad, aztán visszakerül az alaphelyzetébe. Alapértelmezésben egy lejátszás történik, és a befejezett animáció már nem hat az elemre.

A doboz egyszer elmozdul

0 140px

Figyeld meg a mozgást és azt is, hová kerül a doboz a végén. Új lejátszáshoz válts Alaphelyzetre, majd indítsd újra.

Mutasd a kódot + 
@keyframes elore {
  from {
    left: 0;
  }
  to {
    left: 140px;
  }
}
.once-box {
  animation-name: elore;
  animation-duration: 2s;
  animation-timing-function: linear;
}

Az elore egy általunk választott név. A @keyframes és az animation-name ugyanazt a nevet használja.

A végén maradjon a célban

Az előző mozgást használjuk tovább. Csak az animation-fill-mode beállítást változtatjuk meg.

A felső doboznál none az érték: a mozgás végén visszaáll a left: 0. Az alsó doboznál forwards: az animáció utolsó állapota, a left: 140px marad látható.

Indítsd el a két dobozt egyszerre. Mozgás közben ugyanazt csinálják; a különbség a két másodperc letelte után jelenik meg.

  animation-name: elore;

Mindkét doboz az előző példában megadott elore animációt használja.

Mennyi ideig tartson, és mikor induljon?

A mozgás útvonala ugyanaz marad. Az animation-duration egy teljes lejátszás idejét adja meg. Ugyanaz a 140 pixeles út 1s alatt gyorsabb, 3s alatt lassabb.

Az animation-delay: 2s az indulás elé tesz két másodperc várakozást. A késleltetés külön számít: két másodperc várakozás és három másodperc mozgás összesen öt másodperc.

Előbb válassz időzítést, majd indítsd el a példát. A várakozás idején a doboz még az alaphelyzetében áll.

  animation-duration: 1s;

}

/* Késleltetett lejátszás: */

Az időtartam a mozgás hosszát, a késleltetés az indulás előtti várakozást változtatja meg.

Adjunk meg egy köztes állomást

Eddig csak a kezdetet és a véget adtuk meg. A from helyett 0%, a to helyett 100% is írható.

Az új fordulo animációban 50%-nál a doboz a jobb oldalon van, 100%-nál visszaér a bal oldalra. A százalék itt a lejátszás idejének részét jelenti.

A teljes mozgás négy másodperces. Két másodperc alatt jut el a jobb oldalra, majd a következő kettő alatt tér vissza. Ez még mindig egyetlen lejátszás.

A visszaút most a @keyframes része. Új lejátszáshoz válts Alaphelyzetre, majd indítsd újra.

Mutasd a kódot + 
@keyframes fordulo {
  0% {
    left: 0;
  }
  50% {

  100% {
    left: 0;
  }

.middle-box {

}

A 50% nem 50 pixelt és nem a doboz szélességének felét jelenti: a négymásodperces lejátszás felénél tartunk.

Játsszuk le többször

Visszatérünk az első elore animációhoz: a doboz balról jobbra halad. Az animation-iteration-count mondja meg, hányszor játsszuk le.

Az 1 egy, a 3 három lejátszást jelent. Az infinite addig ismétel, amíg az animáció be van állítva az elemre.

Három ismétlésnél a doboz minden új kör elején visszaugrik a bal oldalra. A következő példában ezt az ugrást fogjuk megszüntetni.

0 140px

Egy kör 2s. Három kör késleltetés nélkül összesen 6s. Új lejátszáshoz válts Alaphelyzetre, majd indítsd újra.

Mutasd a kódot + 
.repeat-box {
  animation-name: elore;
  animation-duration: 2s;
  animation-timing-function: linear;
  animation-fill-mode: forwards;
  animation-iteration-count: 1;
}
/* Háromszor: */
.repeat-box {
  animation-iteration-count: 3;
}

/* Folyamatosan: */
.repeat-box {
  animation-iteration-count: infinite;
}

A forwards csak az összes ismétlés befejezése után tartja meg a végállapotot. Végtelen ismétlésnél nem jutunk el a befejezésig.

Fordítsuk meg a lejátszás irányát

A @keyframes elore változatlan marad. Az animation-direction azt mondja meg, milyen sorrendben járjuk be az állapotait.

A normal mindig balról jobbra, a reverse mindig jobbról balra játszik. Az alternate az első körben előre, a másodikban visszafelé halad. Az alternate-reverse visszafelé kezd, aztán előre folytatja.

Az oda-vissza haladáshoz itt nem kell 50%-os állomás. Két külön lejátszás követi egymást, ellentétes irányban.

Mindegyik változat végtelenül ismétel. Az alternate egy teljes oda-vissza útja 4s. Új lejátszáshoz válts Alaphelyzetre, majd indítsd újra.

Mutasd a kódot + 
.direction-box {
  animation-name: elore;
  animation-duration: 2s;
  animation-timing-function: linear;
  animation-iteration-count: infinite;
  animation-direction: normal;
}
/* Oda-vissza: */
.direction-box {
  animation-direction: alternate;
}

/* Mindig visszafelé: */
.direction-box {
  animation-direction: reverse;
}

/* Visszafelé kezdett oda-vissza út: */
.direction-box {
  animation-direction: alternate-reverse;
}

A fordulo animációban egy lejátszás tartalmazta az oda- és visszautat. Itt az elore animáció egy lejátszása csak az egyik irányt járja be.

Azonos idő alatt más ritmusban

Mindhárom doboz ugyanazt az utat járja be három másodperc alatt. Az animation-timing-function azt változtatja meg, hogyan oszlik el a mozgás ezen az időn belül.

A linear egyenletes. Az ease-in-out lassan kezd, középen gyorsabb, a végén lassul. A steps(4, end) négy ugrással teszi meg az utat; az első ugrásig kivár.

Indítsd el őket egyszerre. Egy időben fordulnak vissza, de közben eltérő helyen járhatnak.

.rhythm-box {

A steps(4, end) ennél a 140 pixeles útnál 35 pixeles ugrásokat eredményez. Az animation-duration ettől továbbra is három másodperc.

Mi látszik a várakozás alatt és a végén?

Most különbözik az alaphelyzet és az animáció kezdete: a CSS szerint left: 0, az új kesleltetett animáció első állapota viszont left: 30px. A végállapot továbbra is 140px.

Két másodperc várakozás után két másodperc mozgás következik. A backwards már a várakozás alatt az animáció kezdőállapotát mutatja. A forwards a végállapotot tartja meg. A both mindkettőt megteszi.

Válassz egy értéket, majd indítsd el. Nézd meg külön a várakozás első két másodpercét és a mozgás utáni állapotot.

A doboz helyett mozogjon a droid

A megismert beállításokat most egy képen használjuk. A vízszintes left helyett a transform: translateY(-35px) viszi a droidot 35 pixellel feljebb. Az infinite ismétel, az alternate az irányt váltogatja.

A tempóválasztó az időtartamot változtatja. A Szünet az animation-play-state: paused beállítást adja: a droid az aktuális helyén megáll. Újabb kattintásra onnan folytatja, ahol megállt.

.floating-droid {

  animation-iteration-count: infinite;

  animation-duration: 0.5s;
}

#droid-pause:checked ~ .droid-scene img {

}

A rövid animation alak több beállítást egyesít: a név lebeges, az időtartam 1.5s, az időzítés ease-in-out, az ismétlés infinite, az irány alternate. A késleltetés elhagyva 0s.

Az animation beállításai

animation-name
A @keyframes szabályban megadott név; itt lebeges.
animation-duration
Egy lejátszás időtartama; itt 1.5s, azaz másfél másodperc.
animation-delay
Ennyit vár az indulás előtt. A 0s azonnali kezdést jelent.
animation-iteration-count
A lejátszások száma. Az infinite végtelen ismétlést jelent.
animation-direction
Az alternate miatt a droid először fel, majd visszafelé, le mozog. A normal mindig előre játszik, a reverse mindig visszafelé.
animation-play-state
A paused megállítja a mozgást az aktuális helyen, a running folytatja.
animation-timing-function
A mozgás ritmusa egy lejátszáson belül; például linear, ease-in-out vagy steps(4, end).
animation-fill-mode
Az animáció állapotainak megjelenítése a késleltetés alatt és a befejezés után.
