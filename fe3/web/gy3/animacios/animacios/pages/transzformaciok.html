Transzformációk

A vadászgép mozgatása

A transform segítségével eltolhatjuk, elforgathatjuk, nagyíthatjuk vagy ferdíthetjük a képet. A körülötte lévő elemek helyzete ettől nem változik. A szaggatott keret mutatja, hol volt eredetileg a kép.

translate(55px, -30px)
55 pixellel jobbra és 30 pixellel felfelé tolja a képet.
rotate(30deg)
30 fokkal forgatja el az óramutató járásával megegyező irányba.
scale(1.3)
A szélesség és a magasság is az eredeti 1,3-szorosa lesz.
skewX(-20deg)
Vízszintesen ferdíti a képet, −20 fokos szöggel.
rotateY(55deg)
A függőleges tengely körül forgatja a képet: úgy látszik, mintha oldalról néznénk.
A vadászgép transzformációja
transform: none; translate(55px, -30px) rotate(30deg) scale(1.3) skewX(-20deg) rotateY(55deg)

A szaggatott keret mutatja az eredeti helyet.

</> Mutasd a kódot transform + transform-origin + 
.transform-ship {
  transform-origin: center;
  transition: transform 0.6s ease;
}

#tf-rotate:checked ~ .transform-scene img {
  transform: rotate(30deg);
}
/* Több művelet is összekapcsolható. */
.ship {
  transform: translate(55px, -30px) rotate(30deg);
}

/* A sorrend számít: más eredményt ad! */
.ship {
  transform: rotate(30deg) translate(55px, -30px);
}

A transform-origin a forgatás és méretezés középpontja. A 3D jelenet perspective: 500px értéke adja a térhatást.

KÖZÉPRE IGAZÍTÁS

Középre igazítás 

.centered {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}

A top és left a szülő feléig visz. A translate az elem saját méretének felével tol vissza.

TENGELYEK + MATRIX

További transzformációk

A scaleX csak vízszintesen méretez; a scaleY függőlegesen. A skewX és skewY külön-külön ferdít. 

/* Méretezés, ferdítés, eltolás egy mátrixban: */
transform: matrix(1, 0, 0, 1, 55, -30);
/* Ugyanez egyszerűbben: */
transform: translate(55px, -30px);

A matrix utolsó két száma pixelben értendő.
